プライバシーポリシー

「Celestial Oracle」（以下「本アプリ」）の運営者 futodama（以下「運営者」）は、本アプリにおける利用者に関する情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

2. 本アプリが取り扱う情報

(1) オラクルカードの利用データ

本アプリは、以下の情報を本アプリの機能提供のために取り扱います。

  • 引いたカードの履歴
  • リフレクション（その日の問いに対して、利用者が任意に入力した回答）
  • お気に入りに登録したカード
  • 出会ったカードの情報
  • カードを引いた日付その他履歴管理に必要な情報

これらの情報は、原則として利用者の端末内に保存されます。

また、iOS版において利用者がiCloudを利用できる環境では、Apple Inc.が提供するCloudKitを利用し、履歴、リフレクション、お気に入り、出会ったカード等の情報を利用者のiCloud環境と同期する場合があります。

運営者は、リフレクションの内容を含め、これらの情報を運営者独自のサーバーへ保存しません。

(2) 設定情報

本アプリは、通知設定その他本アプリの利用に必要な設定情報を利用者の端末内に保存する場合があります。

一部の設定情報はCloudKitによる同期対象ではなく、本アプリを削除した場合に消去される場合があります。

(3) 通知

本アプリは、利用者が希望した場合、毎日のオラクルカードを案内するための通知を送信することがあります。

通知の許可および通知設定は、利用者の端末および本アプリの設定から変更できます。

(4) アプリ内課金

本アプリでは、追加デッキその他のデジタルコンテンツについて、AppleのApp StoreおよびStoreKitを利用したアプリ内課金を提供する場合があります。

購入処理はAppleによって行われます。運営者が利用者のクレジットカード番号その他の決済情報を直接取得することはありません。

本アプリは、購入済みコンテンツの提供または復元に必要な範囲で、Appleから提供される取引情報または購入権利に関する情報を利用する場合があります。

(5) 本アプリが直接登録を求めない情報

本アプリには、運営者独自の会員登録機能はありません。

運営者は、本アプリの通常利用にあたり、利用者の氏名、住所、電話番号、メールアドレス等の登録を求めません。

また、本アプリの主要機能は、位置情報、カメラまたはマイクへのアクセスを必要としません。

ただし、利用者がお問い合わせのために運営者へ電子メール等を送信した場合、利用者が任意に提供したメールアドレス、問い合わせ内容その他の情報を運営者が受領する場合があります。

(6) Web版について

本アプリには、iPhone向けのアプリ（以下「iOS版」）のほか、ウェブブラウザで利用できるWeb版（https://celestial.futodama.app/）があります。

Web版では、カード履歴、リフレクション、お気に入り、出会ったカード等のデータおよび設定情報を、利用者がお使いのブラウザ内の保存領域（IndexedDB等）に保存します。運営者は、これらの情報を運営者独自のサーバーへ保存しません。

また、Web版をオフラインでも利用できるよう、Service Workerおよびブラウザのキャッシュ（Cache Storage）を利用して、本アプリの表示に必要なファイルをブラウザ内に保存します。

Web版では、現在、iCloud／CloudKitによる同期、App Store／StoreKitによるアプリ内課金および通知の機能を提供していません。そのため、Web版のデータはiOS版のデータと同期されません。

Web版のアプリ本体は、現在、Cookieを使用していません。

(7) Web版の利用状況の計測

運営者は、Web版の利用状況を統計的に把握し、プロモーション施策を評価するため、Web版で次の操作が行われた際に、その種類と以下の最小限の情報を、運営者が利用するCloudflareの集計機能へ送信し、件数として集計します。

  • Web版を開いたとき：URLに含まれるキャンペーン識別用パラメータ（流入元、媒体、キャンペーン、コンテンツの識別子）、表示言語、ホーム画面に追加したアプリとして起動したかどうか
  • カードを引いたとき：使用したデッキの識別子
  • リフレクションを保存したとき：保存したという事実のみ

この計測では、リフレクションの内容、引いたカードの情報や履歴、氏名、メールアドレス、利用者や端末を継続的に識別するためのIDを送信せず、Cookieも使用しません。

3. 情報の利用目的

本アプリで取り扱う情報は、以下の目的で利用します。

  • 本アプリの機能の提供および維持
  • オラクルカードの履歴、リフレクション、お気に入り、出会ったカードの保存
  • iCloudを利用した対応データの同期および復元
  • 利用者が設定した通知の提供
  • 購入済みコンテンツの提供および復元
  • Web版をオフラインでも利用できるようにするためのデータの保存
  • Web版の利用状況および表示性能の統計的な把握
  • Web版のプロモーション施策の評価
  • 不具合への対応および本アプリの改善
  • お問い合わせへの対応

4. 第三者サービス

本アプリでは、以下の第三者サービスを利用する場合があります。

Apple iCloud / CloudKit

履歴、お気に入り、出会ったカード等の対応データを、利用者のiCloud環境と同期するために利用します。

CloudKitその他Appleのサービスにおける情報の取扱いについては、Appleのプライバシーポリシーその他の規定が適用されます。

Apple App Store / StoreKit

追加コンテンツの購入、購入状態の確認および購入済みコンテンツの復元等のために利用する場合があります。

決済情報の取扱いについては、Appleの規定が適用されます。

Cloudflare（Cloudflare Pages / Cloudflare Web Analytics）

Web版の配信には、Cloudflare, Inc.が提供するCloudflare Pagesを利用しています。Web版へのアクセスの際、通信に必要な情報（IPアドレス、ブラウザの種類、アクセス日時等）がCloudflareによって処理される場合があります。

また、Web版の利用状況および表示性能を統計的に把握するため、Cloudflare Web Analyticsを利用しています。Cloudflare Web Analyticsでは、閲覧されたページ、参照元、国・地域、端末およびブラウザの種類、表示性能等に関する情報が扱われる場合があります。運営者は、Cloudflare Web AnalyticsをCookieを使用しない構成で利用しています。

また、2.(7)の利用状況の計測には、Cloudflare Pages FunctionsおよびCloudflare Workers Analytics Engineを利用しています。

Cloudflareにおける情報の取扱いについては、Cloudflareのプライバシーポリシーその他の規定が適用されます。

運営者は、法令に基づく場合その他正当な理由がある場合を除き、運営者が直接取得した利用者の個人情報を、利用者の同意なく第三者へ提供しません。

5. 広告について

本アプリは、現在、第三者による広告配信を行いません。

そのため、広告配信を目的とした広告識別子の利用や、第三者広告サービスによるトラッキングを本アプリ独自に行うことはありません。

今後、本アプリの仕様変更により広告サービスを導入する場合は、必要に応じて本ポリシーを改定します。

6. データの保存および削除

端末内に保存された本アプリのデータは、本アプリをアンインストールすることにより削除される場合があります。

ただし、CloudKitによる同期対象となっている履歴、リフレクション、お気に入り、出会ったカード等については、同じApple Accountおよび対応するiCloud環境を利用することにより、再インストールまたは機種変更後に復元される場合があります。

通知設定その他一部の端末内設定については、再インストール時に復元されない場合があります。

Web版のデータは、利用者がお使いのブラウザ内に保存されます。ブラウザのサイトデータまたは閲覧データを削除した場合、Web版のカード履歴、リフレクション、お気に入り等のデータも削除されることがあり、運営者はこれを復元できません。また、ブラウザの仕様や設定により、保存されたデータが削除される場合があります。

iCloud上のデータの保存、同期および削除については、Appleが提供するiCloudおよびCloudKitの仕組みが利用されます。

運営者は、通信状況、iCloudの利用状態、Appleのサービス状況その他の事情により、すべてのデータが常に確実に同期または復元されることを保証するものではありません。

お問い合わせにより利用者から提供された情報については、お問い合わせへの対応その他必要な目的が終了した後、法令上または正当な理由により保存する必要がある場合を除き、不要となった情報を適切に削除します。
