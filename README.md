# celestial-oracle-support

「Celestial Oracle」のサポートサイト（プライバシーポリシー・利用規約・免責事項・お問い合わせ先、日本語／英語）です。GitHub Pagesで公開するための、静的HTMLのみのサイトです（JavaScriptなし、外部サービスなし）。

## ファイル構成

```text
celestial-oracle-support/
├─ index.html            トップページ（日本語）
├─ style.css             共通スタイル
├─ privacy/
│  └─ index.html         プライバシーポリシー（日本語）
├─ terms/
│  └─ index.html         利用規約（日本語）
├─ disclaimer/
│  └─ index.html         免責事項（日本語）
├─ en/
│  ├─ index.html         トップページ（English）
│  ├─ privacy/index.html Privacy Policy
│  ├─ terms/index.html   Terms of Use
│  └─ disclaimer/index.html Disclaimer
└─ README.md              このファイル
```

## GitHub Pagesを有効にする

1. リポジトリ画面上部の「Settings」タブを開きます。
2. 左側メニューから「Pages」を選びます。
3. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
4. 「Branch」で `main` を選び、フォルダは `/(root)` のままにします。
5. 「Save」をクリックします。
6. 数分待つと、ページ上部に公開URLが表示されます。

## 内容を修正したいとき

`privacy/index.html`・`terms/index.html`・`disclaimer/index.html`（および`en/`配下の対応するファイル）の文章を直接編集し、GitHubへ再度pushすれば反映されます。
